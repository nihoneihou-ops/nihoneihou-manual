通告係

通告係が、主任・記録係と連携しながら競技者情報と得点を通告するための手順です。

使用するシステムは競技区分で異なります。

  • 本文中のマスター：審判システムを使用します。
  • 本文中のジュニア・シニア：記録システムを使用します。

利用開始前の確認​

端末・キーホルダー・ログインアカウント・端末ID・担当面等の確認は、共通の**「利用開始前の確認」**に従ってください。

競技区分に応じて、次の手順で通告対象を表示します。

泳法競技 マスタークラス​

  1. 審判システムを開きます。
  2. 画面左側のメニューを開きます。端末の表示幅によっては、メニューが画面下部に表示されます。
  3. 通告係用の競技運営画面を開きます。
  4. 第一泳者と次の競技者の情報が表示されていることを確認します。
  5. 第一泳者の泳順・氏名・流派／所属・競技種目・泳向が実際の競技と一致していることを確認します。

泳法競技ジュニア・泳法競技シニア​

  1. 記録システムを開きます。
  2. メニューから**「【通告】競技運営」**を開きます。
  3. 「現在泳者」と「次泳者」が表示されていることを確認します。
  4. 第一泳者の競技者名・競技種目・泳向が実際の競技と一致していることを確認します。
備考

ジュニア・シニアの通告画面には得点を表示しません。審判が提示する得点カードを確認して読み上げ、記録係が記録システムへ入力します。

泳法競技 マスタークラス​

1. 第一泳者を確認する​

  1. 画面に表示されている第一泳者の泳順・氏名・流派／所属・競技種目・泳向を確認します。
  2. 記録係の「次競技候補」と同じ競技者であることを確認します。
  3. 主任・記録係との準備が整っていることを確認します。

2. 競技開始を通告する​

準備が整ったら、競技開始のアナウンスを行います。

このタイミングに合わせて、記録係が審判システムの**「競技開始」**を実行します。これにより審判端末にも当該競技者の採点画面が表示されます。

競技者は、主任の笛等の合図で演技を開始します。

3. 得点を通告する​

演技終了後、審判が採点を入力・確定し、主任が採点結果を確認します。

主任が結果を確定できる状態と判断した後、その進行に合わせて得点を読み上げます。

得点の読み上げが終わると、記録係が審判システムの**「結果確定」**を実行します。

4. 次泳者を確認して通告する​

画面に表示されている次の競技者を確認し、主任・記録係と次の開始準備を行います。

次の競技開始のアナウンスに合わせて、記録係が当該競技者の**「競技開始」**を実行します。審判端末の採点対象も次の競技者へ切り替わります。

以後、同じ手順を繰り返します。

泳法競技ジュニア・泳法競技シニア​

ジュニアとシニアでは、表示される種目構成が異なります。

区分確認する種目
ジュニア1種目目、2種目目
シニア予選予選①、予選②、予選③
シニア決勝決勝①、決勝②

通告ダッシュボードでは、**左側に「現在泳者」、右側に「次泳者」**を表示します。

1. 第一泳者を確認する​

  1. 「現在泳者」に表示されている第一泳者の競技者名・競技種目・泳向を確認します。
  2. 実際に演技する競技者と一致していることを確認します。

2. 競技開始を通告する​

表示内容を確認したうえで、競技開始のアナウンスを行います。

3. 得点を通告する​

審判が提示する得点カードを確認し、審判番号の順に得点を読み上げます。

通告画面には得点は表示されません。 記録係は、通告係の読み上げに合わせて審判番号と得点の対応を確認しながら記録システムへ入力します。

4. 次泳者を確認して通告する​

記録係が現在種目の得点を入力してSaveすると、通告画面の進行状態も更新されます。

端末間の同期には時間差が生じる場合があります。次の競技者の通告準備は、右側に表示されている「次泳者」を参照してください。

次泳者を確認し、実際の競技進行と一致していることを確認したうえで、次の競技開始のアナウンスを行います。

画面が更新されない場合は、共通の「基本的な操作」に記載している同期手順に従います。

棄権​

画面上に対象競技者の棄権表示が出ている場合は、棄権であることを通告します。

通告係が独自に棄権状態を判断したり、画面上の状態を変更したりすることはありません。
