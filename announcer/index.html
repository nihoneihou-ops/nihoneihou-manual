通告係

通告係が、主任・記録係と連携しながら競技者情報と得点を通告するための手順です。

使用するシステムは競技区分で異なります。

  • 本文中のマスター：審判システムを使用します。
  • 本文中のジュニア・シニア：記録システムを使用します。

利用開始前の確認​

端末・キーホルダー・ログインアカウント・端末ID・担当面等の確認は、共通の**「利用開始前の確認」**に従ってください。

競技区分に応じて、次の手順で通告対象を表示します。

泳法競技 マスタークラス​

  1. 審判システムを開きます。
  2. 画面左側のメニューを開きます。端末の表示幅によっては、メニューが画面下部に表示されます。
  3. 通告係用の競技運営画面を開きます。
  4. 第一泳者と次の競技者の情報が表示されていることを確認します。
  5. 第一泳者の泳順・氏名・流派／所属・競技種目・泳向が実際の競技と一致していることを確認します。

泳法競技ジュニア・泳法競技シニア​

  1. 記録システムを開きます。
  2. メニューから**「現在の通告対象」**を開きます。
  3. これから通告する対象競技を選択します。
  4. **「通告ダッシュボード」**が開き、「現在泳者」と「次泳者」が表示されていることを確認します。
  5. 第一泳者の競技者名・競技種目・泳向が実際の競技と一致していることを確認します。
備考

ジュニア・シニアの通告画面には得点を表示しません。審判が提示する得点カードを確認して読み上げ、記録係が記録システムへ入力します。

泳法競技 マスタークラス​

1. 第一泳者を確認する​

  1. 画面に表示されている第一泳者の泳順・氏名・流派／所属・競技種目・泳向を確認します。
  2. 記録係の「次競技候補」と同じ競技者であることを確認します。
  3. 主任・記録係との準備が整っていることを確認します。

2. 競技開始を通告する​

準備が整ったら、競技開始のアナウンスを行います。

このタイミングに合わせて、記録係が審判システムの**「競技開始」**を実行します。これにより審判端末にも当該競技者の採点画面が表示されます。

競技者は、主任の笛等の合図で演技を開始します。

3. 得点を通告する​

演技終了後、審判が採点を入力・確定し、主任が採点結果を確認します。

主任が結果を確定できる状態と判断した後、その進行に合わせて得点を読み上げます。

得点の読み上げが終わると、記録係が審判システムの**「結果確定」**を実行します。

4. 次泳者を確認して通告する​

画面に表示されている次の競技者を確認し、主任・記録係と次の開始準備を行います。

次の競技開始のアナウンスに合わせて、記録係が当該競技者の**「競技開始」**を実行します。審判端末の採点対象も次の競技者へ切り替わります。

以後、同じ手順を繰り返します。

泳法競技ジュニア・泳法競技シニア​

ジュニアとシニアでは、表示される種目構成が異なります。

区分確認する種目
ジュニア1種目目、2種目目
シニア予選予選①、予選②、予選③
シニア決勝決勝①、決勝②

通告ダッシュボードでは、**左側に「現在泳者」、右側に「次泳者」**を表示します。

1. 第一泳者を確認する​

  1. 「現在泳者」に表示されている第一泳者の競技者名・競技種目・泳向を確認します。
  2. 実際に演技する競技者と一致していることを確認します。

2. 競技開始を通告する​

表示内容を確認したうえで、競技開始のアナウンスを行います。

3. 得点を通告する​

審判が提示する得点カードを確認し、審判番号の順に得点を読み上げます。

通告画面には得点は表示されません。 記録係は、通告係の読み上げに合わせて審判番号と得点の対応を確認しながら記録システムへ入力します。

4. 次泳者を確認して通告する​

  1. 右側の**「次泳者」**を確認し、実際の競技進行と一致していることを確認します。
  2. 次泳者の通告を行います。次泳者が棄権表示の場合は、棄権であることを通告します。
  3. 次泳者の通告が完了したことを記録係と確認します。
  4. その後、記録係が現在泳者の得点をSaveします。Saveすると通告側の進行状態が更新されます。
  5. 通告端末でSyncし、「現在泳者」と「次泳者」が次の進行へ切り替わったことを確認します。

記録端末でSaveした内容は、通告端末へ直ちに表示されない場合があります。通告ダッシュボードが更新されない場合は、共通の「基本的な操作」に従って通告端末でSyncします。

警告

記録係がSaveすると通告画面が次へ進みます。次泳者の通告が終わる前にSaveしないよう、記録係とタイミングを合わせてください。

棄権​

注意

棄権情報の事前確認は、招集係等から別途連携される紙を正として行います。通告ダッシュボードは、棄権を初めて知るための連絡手段として使用しません。

  1. 競技開始前に紙の棄権情報を確認し、数人先を含む棄権者を把握します。
  2. 通告ダッシュボード上に対象競技者の棄権表示が出ている場合は、紙の情報と競技者・泳順を照合します。
  3. 次泳者が棄権者の場合は、棄権であることを通告します。
  4. 棄権の通告が完了したことを記録係と確認します。
  5. 記録係が現在泳者をSaveした後、通告端末でSyncし、棄権者を通過して後続の泳者へ進んだことを確認します。

通告係が独自に棄権状態を判断したり、棄権フラグを変更したりすることはありません。

警告

記録画面では数人先の棄権者を事前登録できます。直前泳者がSaveされると、次の棄権者はシステム上「棄権通告済」となり、通告端末のSync後は通告ダッシュボードから通過します。

このため、通告ダッシュボードだけでは棄権情報を事前に把握できません。紙で共有された棄権情報を必ず確認してください。

先頭・連続・全員棄権など、通常泳者のSaveを起点にできない場合は例外操作が必要です。記録係・システム係と確認し、既存の棄権通告完了操作で進行します。
