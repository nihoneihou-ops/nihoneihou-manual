記録係

記録係が、主任の競技進行に合わせて採点結果を確認・記録するための手順です。

使用するシステムは競技区分で異なります。

  • 本文中のマスター：審判システムを使用します。
  • 本文中のジュニア・シニア：記録システムを使用します。

利用開始前の確認​

端末・キーホルダー・ログインアカウント・端末ID・担当面等の確認は、共通の**「利用開始前の確認」**に従ってください。

競技区分に応じて、次の手順で記録対象を表示します。

泳法競技 マスタークラス​

マスターでは種目選択画面はありません。

  1. 審判システムを開きます。
  2. 画面左側のメニューを開きます。端末の表示幅によっては、メニューが画面下部に表示されます。
  3. **「競技運営」**を選択します。
  4. 「現在競技」と「次競技候補」が表示されることを確認します。
  5. 競技開始前は、第一泳者の泳順・競技者名・競技種目・泳向が「次競技候補」に表示されていることを確認します。

この画面は横向きで使用し、左側の「現在競技」と右側の「次競技候補」を同時に確認します。

泳法競技ジュニア・泳法競技シニア​

ジュニア・シニアでは、記録システムを開くと最初に記録対象の競技を選択する画面が表示されます。

  1. 記録システムを開きます。
  2. 表示された競技の中から、これから記録する競技を選択します。
  3. 対象競技の競技者一覧が表示されたことを確認します。
  4. 男女・予選／決勝・実施面など、表示内容が実際の競技と一致していることを確認します。

泳法競技 マスタークラス​

業務手順概要​

競技そのものの進行・判断は主任が行います。記録係は、主任・通告係と連携しながら審判システムへ進行状態を反映し、採点結果を確認・確定します。

1. 競技を開始する​

「競技開始」は、主任の競技進行に合わせて実行します。

  1. 主任・通告係との準備が整っていることを確認します。
  2. 通告係が競技開始のアナウンスを行うタイミングで、第一泳者について**「競技開始」**を実行します。
  3. 第一泳者が「現在競技」に表示されたことを確認します。

「競技開始」を実行すると、各審判の端末にも当該競技者の採点画面が表示されます。また、「次競技候補」には次の未確定競技者が表示されます。

備考

競技者は、競技規則に基づき主任の笛等の合図で演技を開始・終了します。審判システムの「競技開始」は、主任の競技進行に合わせてシステム上の採点対象を切り替える操作です。

2. 採点結果を確認する​

演技終了後、審判が各端末から採点を入力し、**「入力確定」**を行います。

入力された内容は「現在競技」へ自動的に更新されて表示されます。記録係は、次を確認します。

  • 対象の競技者・競技種目が正しいこと
  • 必要な審判の入力が揃っていること
  • 各審判の得点
  • 合計点
  • 最高点・最低点・点差等の確認情報

画面が更新されない場合は、共通の「基本的な操作」に記載している同期手順に従います。

3. 得点通告後に結果を確定する​

  1. 審判の入力が揃ったことを確認します。
  2. 主任が画面上の採点結果・点差等を確認し、結果を確定できる状態であることを判断します。
  3. 主任の進行により、通告係が得点を読み上げます。
  4. 得点の読み上げが終わったら、記録係が**「結果確定」**を実行します。
  5. 「現在競技」の表示が解除されたことを確認します。
  6. 「次競技候補」に表示されている次の競技者を確認します。

4. 次の競技者へ進む​

「次競技候補」には、現在の競技中から次の競技者が表示されています。

  1. 「次競技候補」の競技者・競技種目・泳向を確認します。
  2. 主任・通告係との準備が整うのを待ちます。
  3. 次の競技開始のアナウンスに合わせて、その競技者について**「競技開始」**を実行します。
  4. その競技者が「現在競技」に移り、審判端末にも採点対象として表示されたことを確認します。

泳法競技ジュニア・泳法競技シニア​

業務手順概要​

ジュニア・シニアとも、記録係が行う基本操作は同じです。

ジュニアとシニアでは、選択する入力画面と種目数だけが異なります。

区分入力する画面
ジュニア1種目目、2種目目
シニア予選予選①、予選②、予選③
シニア決勝決勝①、決勝②

1. 現在の競技者・種目を開く​

  1. 競技者一覧から現在の泳順の競技者を選択します。
  2. 現在実施している種目に対応する入力画面を開きます。
  3. 競技者名・流派・所属・競技種目・泳向が実際の競技と一致していることを確認します。

2. 得点を記録する​

  1. 各審判が提示する得点カードを通告係が読み上げます。
  2. 通告係の得点読み上げに合わせて、審判番号と得点の対応を確認しながら各欄へ入力します。
  3. 入力漏れ・入力位置の誤りがないことを確認します。
  4. 得点入力後もすぐにはSaveせず、通告係が右側の「次泳者」を確認し、次泳者の通告を完了するのを待ちます。
  5. 通告係から次泳者の通告完了を確認したら、Saveします。

必要な得点がすべて入力された状態でSaveすると、その種目の確定状態として扱われ、通告画面の進行にも反映されます。

警告

Saveは通告画面を次へ進める操作でもあります。 次泳者の通告が終わる前にSaveしないでください。次泳者が棄権の場合も、通告係が棄権の通告を終えたことを確認してからSaveします。

備考

Save後は通告端末側の表示更新に時間差が生じる場合があります。通告係が通告端末で「Sync」し、次の「現在泳者」「次泳者」へ更新されたことを確認します。

3. 次の種目・競技者へ進む​

同じ競技者に次の種目がある場合は、対応する入力画面を開いて同じ手順で入力します。

現在の競技者の処理が終わったら、競技者一覧へ戻り、次の泳順を確認します。

シニア決勝も、決勝進出者・決泳順が確定して対象競技として表示された後は、予選と同じ入力手順です。

0点の入力​

0点は有効な得点です。0点の場合は空欄にせず、正式な得点として 0 を入力します。

この扱いはジュニア・シニアで共通です。

棄権​

棄権時は通常の得点入力を行いません。

ジュニア・シニア​

棄権情報は、招集係等から連携された紙と対象競技・泳順・競技者を照合して登録します。通告係が棄権者を事前に把握できるよう、記録画面への登録とは別に、紙での連携を必ず行います。

  1. 紙で連携された棄権情報と、対象競技・泳順・競技者を照合します。
  2. 記録画面で対象競技者を棄権として登録します。
  3. 棄権者の得点欄には入力しません。
  4. 通常泳者をSaveする前に、通告係が右側の「次泳者」を通告し、次泳者が棄権者の場合は棄権の通告を終えたことを確認します。
  5. 通告完了後に現在泳者をSaveします。次泳者が棄権者の場合、システムがその棄権者を自動的に「棄権通告済」へ更新します。
  6. 通告係が通告端末でSyncし、後続の泳者へ進んだことを確認します。
警告

数人先の棄権者を記録画面へ先に登録できますが、直前泳者のSave後に「棄権通告済」となり、通告端末のSync後は通告ダッシュボードから通過します。通告ダッシュボードだけを棄権情報の連絡手段にしないでください。

先頭・連続・全員棄権など、通常泳者のSaveを起点にできない場合は、既存の棄権通告完了操作を例外として使用します。対象と順番を確認し、通告係と連携して実行してください。

マスター​

マスターの具体的な棄権操作は現在整理中です。主任・記録係・通告係の役割分担を含めて別途確定したうえで本ガイドへ反映します。

点数訂正​

競技進行中に記録係の判断で点数訂正は行いません。

訂正が必要となった場合は、通常の競技進行とは切り分け、主任・システム係と確認したうえで対応します。
