AccessとのCSV連携

ジュニア・シニアでは、Accessを継続利用しながら新システムとの間でCSVを受け渡します。ファイルの工程・出力日時を取り違えないことが重要です。

1. ジュニア​

基本フロー:

Access → Raw → 取込 → 競技 → 20002結果CSV → Access

  1. 大会前のAccess確定データを新システムの所定Rawへ取り込みます。
  2. 所定の取込処理を実行します。
  3. 競技・結果確定後、帳票 20002｜泳法競技ジュニア結果CSV出力 を実行します。
  4. PCへダウンロードされたCSVを確認します。
  5. そのCSVをAccessへ返却します。

Google Sheetsの 帳票出力結果 からCSVを作り直したり、CSVをExcelで上書き保存したりしないでください。

2. シニア予選から決勝​

基本フロー:

Access → Raw → 取込 → 予選 → 30002 → Access処理 → Raw → 取込 → 決勝 → 30003 → Access

予選結果返却​

  1. 予選結果が確定したら 30002｜泳法競技シニア予選結果CSV出力 を実行します。
  2. ダウンロードされたCSVのファイル名・出力日時を確認します。
  3. Accessへ取り込み、Access側で決勝用処理を実行します。

Access処理後のデータを新システムへ戻す​

  1. Access側で決勝用処理を行った後のデータを出力します。
  2. 泳競男取込Raw / 泳競女取込Raw の対象データとして戻します。
  3. 所定の取込処理を実行します。
  4. 決勝対象・泳順等が反映されたことを確認します。

決勝結果返却​

  1. 決勝結果・順位確定後、30003｜泳法競技シニア決勝結果CSV出力 を実行します。
  2. 最新のCSVであることを確認します。
  3. Accessへ返却します。

3. Rawデータの注意​

シニアのRawは、工程ごとのAccess原本スナップショットとして扱います。

  • 30002前: 大会開始前のAccessベースライン
  • 30003前: 30002返却後にAccessで決勝処理した結果

連携テストや別工程のデータでRawを上書きした場合は、セルを手修正して合わせず、正しいAccess出力から入れ直して所定の取込処理を再実行してください。

4. CSVを取り違えないための確認​

  • 帳票出力画面に表示されたファイル名とダウンロードファイル名が一致している
  • 出力日時が今回の工程と一致している
  • 20002 / 30002 / 30003を混同していない
  • 同種CSVが複数ある場合は最新ファイルを明確にする
  • CSVを開いて確認しても上書き保存しない

5. エラー時​

結果CSVが出ない場合は、競技結果の確定状態と帳票出力メッセージを確認します。Rawの内容に疑義がある場合は、手修正せずAccess側の正しいデータから工程を戻して確認してください。
