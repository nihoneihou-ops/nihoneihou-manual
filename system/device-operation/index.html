タブレットの準備・切替・回収

2026大会で使用するタブレットは全16台です。1日目（8/22）は16台を使用し、2日目（8/23）はそのうち2台を使用します。

16台を効率的に運用するため、1日目は実機13・14を途中で役割変更します。また、実機07・08は1日目終了後も会場に残し、2日目のA面記録／通告用として使用します。

事前準備

端末セットアップを始める前に、使用するGoogleアカウントについて、必要なAppSheetアプリへの共有設定と事前アクセス確認が完了していることをシステム係で確認してください。共有設定の追加・変更は端末上では行わず、事前準備として完了させます。

1. 大会開始前​

次の順で確認します。

  1. 使用する全タブレットを起動します。
  2. Wi-Fi を確認します。
  3. 指定Googleアカウントでログイン済みか確認します。
  4. AppSheetアプリを開けることを確認します。
  5. 端末ID・担当面・役割と実機ラベルが一致していることを確認します。
  6. Sync を実行します。
  7. 記録・通告タブレットは担当画面まで開きます。
  8. 最初に実施する競技名・面・先頭泳者が実際のプログラムと一致していることを確認します。

各確認項目のOK基準​

確認項目OKとする状態
Wi-Fi指定されたネットワークに接続しており、AppSheetのSyncが通信エラーなく完了する
Googleアカウントその端末の役割に指定されたGoogleアカウントでログインしている
AppSheetアクセス対象アプリを開け、「アクセス権がありません」等のエラーが表示されない
端末ID実機ラベルの面・役割とAppSheetの端末IDが一致している
Syncエラーなく完了し、最新の表示へ更新される
対象競技次に実施する競技名、面、競技区分、性別、予選／決勝等が実際の進行と一致する
先頭泳者最初に実施する泳順・氏名がプログラムと一致する
役割画面記録／通告／審判／主任それぞれに必要な画面が表示される
注記

Wi-Fiアイコンが表示されているだけでは通信確認完了としません。AppSheetのSyncが実際に成功することまで確認してください。

各係へ引き渡した後に利用者自身へ設定変更を求めないよう、システム係がここまで確認してから配置します。

2. 競技切替時の確認​

前の競技が終了し、次の競技へ切り替わる合間には、毎回すべての設定をやり直す必要はありません。通常は次の短縮チェックを行います。

  1. Syncを実行する。
  2. 次の競技名・面が正しいことを確認する。
  3. 競技区分・性別・予選／決勝等が実際の進行と一致することを確認する。
  4. 先頭泳者の泳順・氏名がプログラムと一致することを確認する。
  5. 担当する役割画面が正しく表示されていることを確認する。

大会開始前、端末を新たに使用するとき、またはGoogleアカウント／端末IDを変更した直後は、短縮チェックではなく前節のフルチェックを実施します。

3. 8月22日の切替ポイント​

13:15頃　男子立体予選（C面）​

  • 実機13: C面 記録、端末ID T-C-REC
  • 実機14: C面 通告、端末ID T-C-ANN

この競技終了後、2台をB面マスター用へ切り替えます。

14:10～14:30頃　マスター準備​

  • 実機13: C面 記録 T-C-REC → B面 審判5 T-B-05
  • 実機14: C面 通告 T-C-ANN → B面 主任 T-B-CHIEF

切替時は次の順で確認します。

  1. 指定された役割アカウントへ切り替える。
  2. AppSheetの端末IDを上記B面マスター用IDへ変更する。
  3. Syncする。
  4. 画面上の面・役割を確認する。
  5. 審判5／主任に必要な画面が表示されることを確認する。
  6. B面マスターの競技名と先頭泳者が正しく表示されていることを確認する。
注意

切替は競技開始直前まで持ち越さず、14:10～14:30頃の準備時間内に完了させてください。

マスター終了後​

実機13・14を元のC面用へ戻します。

  • 実機13: B面 審判5 T-B-05 → C面 記録 T-C-REC
  • 実機14: B面 主任 T-B-CHIEF → C面 通告 T-C-ANN

役割アカウントと端末IDの両方を戻した後、必ずSyncし、面・役割が戻っていることを確認します。

4. 8月22日終了時​

2日目に残すタブレット:

  • 実機07: A面 記録、端末ID T-A-REC
  • 実機08: A面 通告、端末ID T-A-ANN

実機07・08は設定を変更せず、指定場所で充電します。

残る14台は1日目で返却するため、次を行います。

  1. 未同期データがないことを確認する。
  2. 必要に応じてSyncする。
  3. 実機13・14がC面用へ戻っていることを確認する。
  4. 返却対象14台が揃っていることを確認する。
  5. 充電器・ケーブル等の付属品を確認する。
  6. 返却対象のタブレットと付属品を梱包する。

5. 8月23日​

使用するのは実機07・08の2台です。

大会開始前に次をフルチェックします。

  • 充電状態
  • Wi-Fi（Sync成功まで確認）
  • 指定Googleアカウント
  • 実機07が T-A-REC、実機08が T-A-ANN であること
  • Sync
  • 記録／通告画面
  • 最初に実施する競技・面・先頭泳者

女子決勝から男子決勝への切替時は、Sync後に男子決勝・A面・先頭泳者が正しく表示されることを確認し、端末設定自体は変更せず継続して使用します。

大会終了後、最終Syncを実行して回収します。

6. 不一致がある場合​

担当・面・表示が合わない場合は、そのまま競技を開始せずシステム係が修正します。利用者側で設定を試行錯誤しないでください。

確認順序は、Sync → ログインアカウント → 端末ID → 対象競技 → 面・先頭泳者 → 役割画面を基本とします。アカウント・端末IDを変更した場合は、必ずSync後に画面表示まで確認してください。
