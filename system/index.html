システム係

システム係は、大会当日のシステム運用全体を担当します。本ページを入口として、必要な作業へ進んでください。

新システム関連の主な作業​

分野主な作業
タブレット運用タブレットの起動・ログイン・端末ID確認、配布、競技途中の設定切替、回収・梱包
ライブプログラム運用進行ステータス、プログラム公開／非公開、お知らせの更新
Access連携Access→新システム、新システム→AccessのCSV受け渡し
帳票出力マスター結果一覧、マスタークラス賞状、Access返却CSV等の出力
映像記録競技開始前に各面へビデオカメラ・マイクを設置
障害対応Sync、反映エラー、CSV・帳票出力失敗等の一次切り分け
注意

パスワード、個別アカウントの詳細、データ補正手順等は公開操作ガイドには記載しません。必要な場合は内部手順を参照してください。

1. 大会開始前​

タブレット運用​

2026大会で使用するタブレットは全16台です。

日使用台数運用
1日目（8/22）16台全16台を使用。効率的に運用するため、途中で実機13・14の役割・端末設定を切り替える
2日目（8/23）2台実機07・08を1日目終了後も会場に残し、A面の記録／通告用として使用する

大会開始前は次を確認します。

  • 使用する全タブレットを起動する
  • Wi-Fi、指定Googleアカウント、AppSheetを確認する
  • 端末ID・担当面・役割と実機ラベルが一致していることを確認する
  • Syncを実行してエラーがないことを確認する
  • 記録・通告端末は対象画面まで開いておく

詳細は タブレットの準備・切替・回収 を参照してください。

PC・帳票​

  • 帳票出力に使用するGoogleアカウントで帳票出力Spreadsheetを開けることを確認する
  • マスタークラス賞状作成PCは、大会前にセットアップ・PDF生成テストまで完了させる
  • AccessとのCSV受け渡しに使用するPC・フォルダを確認する

映像記録​

競技開始前に、各面へビデオカメラおよびマイクを設置します。

2. 競技中に発生するシステム作業​

タブレット設定を変更する箇所​

通常は大会中にタブレット設定を変更しません。2026大会では、16台を効率的に運用するため、実機13・14を1日目途中で切り替えます。

おおよその時刻作業
8/22 13:15頃実機13・14をC面の記録／通告として使用
8/22 14:10～14:30頃C面終了後、実機13・14をB面マスター用の審判5／主任へ切替。ログイン・端末ID変更後にSyncし、面・役割を確認
マスター終了後実機13・14をC面の記録／通告設定へ戻し、Syncして確認
8/22終了時実機07・08を翌日のA面記録／通告用として設定を維持して会場に残す。その他14台は回収・梱包する
8/23開始前実機07・08の充電・Wi-Fi・端末ID・Syncを確認

設定切替は、競技開始直前ではなく上記の準備時間内に完了させます。

ライブプログラム運用​

当日は専用の運行管理Google Sheetで次の3つを操作します。

  • ライブ進行: 招集中・実施中・終了等を更新
  • 公開管理: 対象プログラムを公開／非公開
  • お知らせ管理: お知らせの作成・公開・停止

操作方法は ライブプログラムの進行・公開・お知らせを管理する を参照してください。

Accessとのデータ受け渡し​

ジュニア・シニアは、競技結果をAccessへ返却する工程があります。特にシニアは予選と決勝の間にAccess処理を挟むため、ファイルの取り違えに注意します。

詳細は AccessとのCSV連携 を参照してください。

帳票出力​

マスタークラスでは、結果確定後に結果一覧・賞状等を出力します。Access返却CSVも同じ帳票出力基盤から出力します。

詳細は 帳票・CSVを出力する を参照してください。

3. 競技終了後​

  • 未同期データがないことを確認する
  • 必要なCSV・帳票が最新結果で出力されていることを確認する
  • 実機13・14がC面用設定へ戻っていることを確認する
  • 8/22は実機07・08を翌日用として充電し、その他14台を回収・梱包する
  • 8/23終了後は実機07・08を最終Syncして回収する

4. エラーが発生した場合​

まず、どの系統の問題かを切り分けます。

  • AppSheet表示・Sync → タブレット、通信、対象アカウント、端末IDを確認
  • ライブプログラム → 反映状態 を確認し、必要に応じて再同期
  • CSV／帳票 → 出力条件、完了メッセージ、ダウンロードファイル名を確認
  • Access連携 → 使用しているCSVの工程・出力日時を確認

本番データをその場で手修正して合わせず、正本・所定の取込／出力経路から復旧してください。
