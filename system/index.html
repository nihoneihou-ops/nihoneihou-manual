システム係

システム係が、大会前に各タブレットを正しい用途・面・アカウントへ設定し、各係へ引き渡すまでの手順です。

事前準備の考え方​

審判システム・記録システムは、端末設定やログイン状態により表示する競技・面・操作内容が変わります。

各係へログインや端末設定の確認を求めずに済むよう、システム係が競技開始前に端末・アカウント・端末設定・キーホルダー・表示内容まで一括して確認します。

大会当日に使用するWindows PCについても、必要なローカル実行プログラムやテンプレートを大会前にセットアップし、動作確認まで完了させます。

マスタークラス賞状作成​

マスタークラス賞状作成のセットアップ・実行・トラブル対応は、公開操作ガイドには掲載しません。システム係は、Private Repositoryで管理する内部手順を参照してください。

1. 端末一覧を準備する​

使用する全タブレットについて、次を整理します。

確認項目内容
端末識別タブレットを識別できる番号・名称
担当審判／主任／記録係／通告係等
担当面A面／B面／C面等
利用システム審判システム／記録システム
利用用途採点、記録、通告表示等
端末ID各システムで設定する端末ID
ログインアカウント端末で使用するGoogleアカウント
キーホルダー表示実機に付ける担当・面の表示

ログインアカウントは役割単位で確定しています。具体的なメールアドレスと実機番号の対応は、公開しない内部手順「2026大会 システム係向け端末運用計画」を正本とします。

注意

パスワード等の認証情報は公開操作ガイドへ記載しません。必要な認証情報は別途管理・共有します。

2. キーホルダーを取り付ける​

各タブレットに、少なくとも担当と面が判別できるキーホルダーを取り付けます。

設定した端末とキーホルダーを取り違えないよう、設定作業中から同じ組み合わせを維持してください。

3. ログインアカウントを確認する​

  1. 端末ごとの指定Googleアカウントでログインします。
  2. 対象の審判システムまたは記録システムを開けることを確認します。
  3. 別の個人アカウント等で開いていないことを確認します。

この確認はシステム係が実施します。各係へ引き渡した後に、利用者自身へアカウント確認・切替を求めない運用とします。

4. 端末設定を確認する​

各端末について、利用するシステムの端末ID・担当面・端末種別を設定または確認します。

設定後、次を確認します。

  • キーホルダーに表示した担当とシステム上の端末種別が一致している
  • キーホルダーに表示した面とシステム上の面が一致している
  • 使用する係に必要なメニューが表示される
  • 他の係専用の操作画面が誤って主画面になっていない

5. 係別の表示を確認する​

審判​

  • 各審判の座席に正しいタブレットを配置する
  • マスターの採点画面を表示できる
  • 審判番号・担当面が正しい
  • 記録係が「競技開始」を実行した際に、対象競技者が表示される状態である

主任​

  • 主任の座席に正しいタブレットを配置する
  • 主任用画面を表示できる
  • 担当面の採点状況・点差等を確認できる
  • 記録係・通告係と同じ競技者を確認できる

記録係（マスター）​

  • 記録係の作業机に正しいタブレットを配置する
  • 審判システムのメニューに「競技運営」が表示される
  • 「現在競技」「次競技候補」が担当面に応じて表示される
  • 「競技開始」「結果確定」等、記録係に必要な進行操作が表示される
  • マスターの棄権操作は確定済みの運用手順に従い、確認中の操作を本番データで試さない

記録係（ジュニア・シニア）​

  • 記録係の作業机に正しいタブレットを配置する
  • 記録システムを開ける
  • 現在進行中の競技から入力対象競技を選択できる
  • 選択後、対象競技の競技者一覧を表示できる

通告係（ジュニア・シニア）​

  • 通告係の作業机に正しいタブレットを配置する
  • 記録システムのメニューに「現在の通告対象」が表示される
  • 対象競技を選択すると「通告ダッシュボード」が開く
  • 担当面の「現在泳者」「次泳者」が表示される
  • タブレットを横向きにした状態で、「現在泳者」を左、「次泳者」を右に配置して左右に並んで表示されることを確認する
  • 上下に並んでいる場合は、ダッシュボードのグリッド配置を修正して左右配置に戻す
  • 棄権者を記載した紙が通告係・記録係へ共有される運用を確認する

6. Sync・通信を確認する​

各端末で、使用するシステムの**「Sync」**が正常に完了することを確認します。

特に、マスターの審判・主任・記録係、およびジュニア・シニアの記録係・通告係のように複数端末で連携する組み合わせは、1台だけでなく相互に表示が更新されることを確認します。

ジュニア・シニアでは、記録端末側のSave後に通告端末側でSyncし、「現在泳者」「次泳者」が更新されることを大会前のテストデータで確認します。本番データを使った確認操作は行いません。

7. 各係へ引き渡す直前に確認する​

端末を各係へ渡す前に、システム係が1台ずつ次を確認します。

  1. キーホルダーの担当・面が正しい
  2. 指定アカウントでログイン済み
  3. 端末ID・端末種別・面が正しい
  4. 必要なシステム・メニューを開ける
  5. 対象競技の情報が表示されている
  6. Syncが正常に完了する

確認後、記録係・通告係は各作業机へ、審判・主任は各座席へ、キーホルダーの表示どおりに端末を配置します。

8. 競技開始前の最終確認​

競技開始前に、各担当面で次を確認します。

  • マスターでは、記録係の「次競技候補」に第一泳者が表示されている
  • 主任・記録係・通告係が同じ第一泳者を確認できている
  • 記録係が「競技開始」を実行すると、審判端末へ第一泳者が表示される
  • ジュニア・シニアでは、記録係が対象競技の競技者一覧を表示できる
  • 通告係が「現在の通告対象」から同じ競技を選択し、「通告ダッシュボード」で「現在泳者」「次泳者」を確認できる
  • 棄権者を記載した紙が記録係・通告係へ共有されている

不一致がある場合は競技開始前に修正し、各係には設定変更を依頼せずシステム係が対応します。

9. ライブプログラムの進行ステータスを更新する​

ライブプログラムでは、競技・審査・式典の進行状況を参加者向けに表示します。当日は専用の「ライブプログラム運行管理」Google Sheetを開き、進行状況に合わせてステータスを更新します。

この作業のためにシステム係の人数を増やすことを前提とはしていません。操作自体はチェックボックスを1つ進めるだけですが、実際の競技・審査進行と表示がずれないよう、進行を把握している担当者と連絡を取りながら更新してください。

基本操作​

  1. ライブプログラム運行管理Sheetの「ライブ進行」を開きます。
  2. 対象プログラムの現在状態を確認します。
  3. 次の有効なステータスのチェックボックスをONにします。
  4. 「反映状態」が 反映済 になったことを確認します。
  5. 公開中のライブプログラムについて、必要に応じて表示が追従していることを確認します。

通常のステータス例:

  • 競技: 開始前 → 招集中 → 実施中 → 終了
  • 審査: 開始前 → 招集中 → 実施中 → 審査終了 → 結果確定
  • 式典: 開始前 → 実施中 → 終了
  • 速報対象競技: 開始前 → 招集中 → 実施中 → 速報中 → 終了

そのプログラムで使用しないステータスは操作できません。現在状態のチェックを外すと、直前の有効ステータスへ1段戻せます。

進行との連携​

ステータスを時刻だけで機械的に進めず、実際の招集・開始・終了等を確認して更新します。システム係が直接状況を把握できない場合は、進行担当者・記録係等から状況を確認してから操作してください。

反映されない場合​

  • まず「反映状態」が 反映済 / エラー のどちらか確認します。
  • 表示が合わない場合は、メニュー ライブ進行管理 → 最新状態を再同期 を実行します。
  • 専用Sheetが使用できない場合は、従来のAppSheet側の進行操作を非常用手段として使用します。
  • 復旧後は専用Sheetで「最新状態を再同期」し、現在状態を合わせます。
注意

ステータス以外のセルは通常編集しません。プログラム名・予定時刻・内部管理情報等は変更しないでください。

端末・アカウント対応方針​

大会用アカウントは、個人ではなく役割単位で割り当てます。

担当対象面端末ID使用する役割アカウント
審判1～5A面／B面T-A-01～05／T-B-01～05各審判番号に対応する大会審判用
主任A面／B面T-A-CHIEF／T-B-CHIEF大会審判主任用
記録係A面／B面／C面T-A-REC／T-B-REC／T-C-REC大会記録用
通告係A面／B面／C面T-A-ANN／T-B-ANN／T-C-ANN大会通告用

同じ役割アカウントでも、端末IDによって担当面を切り替えます。システム係は、ログイン中の役割アカウントと端末IDの組合せが正しいことを確認してください。

注意

具体的なメールアドレス、パスワード、実機番号との対応は公開操作ガイドへ記載しません。システム係は内部の端末運用計画を参照してください。
