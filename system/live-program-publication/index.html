ライブプログラムの進行・公開・お知らせを管理する

ライブプログラムは、専用の「ライブプログラム運行管理」Google Sheetで操作します。公開URLやシステムの再デプロイを当日に変更する必要はありません。

当日の通常運用では、次の順に確認・操作します。

優先タブ用途
1ライブ進行招集中・招集完了・実施中・終了等の進行ステータスを更新
2お知らせ管理公開画面上部のお知らせを作成・掲載・停止
3公開管理プログラムを公開画面へ表示する／隠す。通常は原則操作しない

1. ライブ進行 を更新する​

ライブ進行 は、当日の競技・審査・式典の実際の進行に合わせて更新します。

  1. 対象プログラムの現在状態を確認します。
  2. 次の有効なステータスのチェックボックスをONにします。
  3. 反映状態 が 反映済 になったことを確認します。
  4. 公開中のライブプログラムが自動更新され、表示が追従することを必要に応じて確認します。

通常の遷移:

  • 競技: 開始前 → 招集中 → 招集完了 → 実施中 → 終了
  • 速報対象競技: 開始前 → 招集中 → 招集完了 → 実施中 → 速報中 → 終了
  • 審査: 開始前 → 招集中 → 招集完了 → 実施中 → 審査終了 → 結果確定
  • 式典: 開始前 → 実施中 → 終了

そのプログラムで使用しない状態は操作できません。現在状態のチェックを外すと、直前の有効状態へ1段戻せます。

注意

予定時刻だけを見て機械的に進めず、実際の招集・開始・終了を確認して更新してください。状況を直接把握できない場合は、進行担当者・記録係等へ確認してから操作します。

招集完了後の事前確認​

招集係等から招集完了の連絡を受けたら、対象プログラムを 招集完了 へ進めます。この時点で、記録システムの対象競技一覧と通告画面の現在泳者・次泳者が表示されます。

記録係・通告係は、第一泳者、次泳者、種目、泳向、棄権表示等を競技開始前に確認します。実際の競技開始を確認してから 実施中 へ進め、表示確認だけのために 実施中 を先行設定しないでください。

2. お知らせ管理 でお知らせを掲載する​

競技進行上の案内、表示上の注意事項などを公開画面上部へ出す場合に使用します。通常運用では、公開管理 よりもこちらを優先して使用します。

新しいお知らせを掲載する​

  1. 空いている行の メッセージ に本文を入力します。
  2. 重要度 を 通常 / 重要 / 緊急 から選択します。
  3. 必要な場合だけ 公開開始日時 / 公開終了日時 を入力します。
  4. 本文・重要度を確認して 公開 をONにします。
  5. 反映状態=反映済 を確認します。
  6. 表示状態 が 公開中 または 公開待ち になったことを確認します。

本文を入力した時点では、非公開の下書きとして登録されます。内容確認後に公開ONにしてください。

重要度​

重要度用途
通常一般的なお知らせ
重要特に注意してほしい案内
緊急緊急性の高い案内

表示状態・公開期間​

  • 非公開: 公開OFF
  • 公開待ち: 公開ONだが公開開始日時前
  • 公開中: 公開条件を満たしている
  • 公開終了: 公開終了日時を経過済み

開始日時を未来にするとその時刻までは表示されません。終了日時を設定すると、その時刻以降は自動的に表示されなくなります。即時掲載する場合は開始・終了日時を空欄にします。

掲載を停止する​

対象行の 公開 をOFFにします。本文は削除されず非公開状態で保持されます。ライブプログラムの自動更新後に表示されなくなったことを確認します。

3. 公開管理 でプログラムの公開対象を変更する​

注記

通常の大会運用では、公開管理 は原則として操作しません。 大会前に設定した公開対象をそのまま使用し、当日は ライブ進行 と、必要に応じて お知らせ管理 を更新します。

プログラムそのものを公開画面へ表示する／隠す必要が生じた場合だけ使用します。

  1. 開催日・開始予定・プログラム名を確認します。
  2. 公開する場合は 公開 をONにします。
  3. 非公開へ戻す場合はOFFにします。
  4. 反映状態=反映済 を確認します。
  5. ライブプログラムの自動更新後に表示／非表示が切り替わったことを確認します。

プログラムをすべて非公開にしていても、公開中のお知らせは独立して表示できます。

4. 反映状態​

ライブ進行、お知らせ管理、公開管理 では、操作後に 反映状態 を確認します。

  • 反映中: 更新処理中
  • 反映済: 正本への更新完了
  • エラー: 更新または再描画に失敗

反映中 の間は連続操作を避けます。

5. 表示が合わない場合​

進行ステータス​

  1. 反映状態 を確認します。
  2. メニュー ライブ進行管理 → 最新状態を再同期 を実行します。
  3. 再同期後の状態を確認します。

公開・お知らせ​

  1. 反映状態 を確認します。
  2. メニュー 公開・お知らせ管理 → 公開・お知らせを再同期 を実行します。
  3. 再同期後のチェック状態・お知らせを確認します。
  4. 公開ライブプログラムを再読込します。

エラー が続く場合は同じ操作を繰り返さず、システム担当へ連絡してください。専用Sheetが利用できない場合は、従来の管理経路を非常用として使用し、復旧後に再同期します。

6. 2026大会で確認済みの動作​

大会前の実環境テストで次を確認済みです。

  • 進行状態の更新と正本反映
  • 正本の公開状態・お知らせの管理画面への同期
  • 非公開お知らせ下書きの作成・ID自動採番・ログ記録
  • お知らせ公開ON → ライブプログラム表示
  • お知らせ公開OFF → 自動更新で非表示
  • 公開管理 の公開ON/OFF → ライブプログラム表示／非表示

当日は上記の確定済み操作を使用し、公開URL変更や再デプロイは行いません。
