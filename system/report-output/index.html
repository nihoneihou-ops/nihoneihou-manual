帳票・CSVを出力する

大会当日は、Google Sheetsの帳票出力基盤から結果一覧・Access返却CSV・マスタークラス賞状用CSV等を出力します。

1. 共通操作​

  1. 帳票出力 Spreadsheetを開きます。
  2. 帳票出力 シートで 帳票ID｜帳票名 を確認して対象帳票を選択します。
  3. 大会・性別等、帳票ごとの条件を指定します。
  4. 出力を実行します。
  5. 画面下部の結果欄で、完了・対象なし・エラーを確認します。
  6. Sheet出力型は 帳票出力結果、CSV出力型はPCのダウンロードフォルダを確認します。

同種のCSVを再出力した場合は別日時のファイルが保存されるため、使用する最新ファイルを明確にしてください。

2. マスター結果一覧（10002）​

使用タイミング​

マスタークラスの結果入力・確認後、結果一覧が必要になった時点で出力します。結果修正後は再出力し、最新の一覧を使用します。

操作​

  1. 帳票 10002｜マスター結果一覧 を選択します。
  2. 対象大会を選択します。
  3. 性別・その他条件は指定しません。
  4. 出力を実行します。
  5. 帳票出力結果 の最新 出力_マスター結果一覧_... シートを確認します。

確認​

  • 対象大会
  • 選手・泳順・種目
  • 点数合計・順位
  • 複数ページの場合に明細欠けがないこと
  • 結果入力状況と一覧が一致していること

3. マスタークラス賞状（10004）​

使用タイミング​

マスタークラス順位確定後、表彰前に作成します。

操作​

  1. 賞状作成用Windows PCのセットアップが完了していることを確認します。
  2. 帳票 10004｜マスタークラス賞状 を選択します。
  3. 対象大会を選択します。
  4. 通常はその他条件を空欄にします。
  5. 出力を実行し、賞状用CSVがPCへダウンロードされたことを確認します。
  6. 賞状作成PCの マスタークラス賞状作成 を実行します。
  7. 生成されたPDFを確認します。
  8. 内容確認後、制定済み賞状用紙へ100%（実際のサイズ）で印刷します。

PDF確認​

  • 各類型1～3位が対象になっている
  • 大会名・表彰日・類型・順位・競技流派・選手名が正しい
  • フォント・レイアウトに問題がない
  • 制定用紙に既印刷の外枠・印影等がPDFへ重複していない

順位や氏名等を修正した場合はCSVから再生成し、古いPDFとの取り違えに注意します。

4. Access返却CSV​

次の帳票はPCへCSVを直接ダウンロードし、Accessへ返却します。

  • 20002: ジュニア結果
  • 30002: シニア予選結果
  • 30003: シニア決勝結果

詳細な順序は AccessとのCSV連携 を参照してください。

5. 出力で問題が起きた場合​

  • 出力条件を確認する
  • 結果欄のメッセージを確認する
  • CSVの場合はダウンロードファイル名・日時を確認する
  • 結果修正後は古い出力物を使わず再出力する
  • データ構造やRawをその場で手修正しない

賞状PDF生成に失敗する場合は、システム係の内部手順にある賞状作成PCセットアップ／トラブル手順を参照してください。
